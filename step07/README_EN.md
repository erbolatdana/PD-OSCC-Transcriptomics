# Step 07: fixed-panel cross-validation and external OSCC validation

This directory reproduces two saved **corrected** analyses: 07A, 10-fold
cross-validation of a fixed five-gene panel, and 07D, external OSCC evaluation
in GSE37991. It does not discover or select the panel. Run the wrapper
`07_machine_learning_reproduction.R`, not the scripts in `source/` separately.

## Requirements and inputs

R and the packages `Biobase`, `caret` and `pROC`, including their dependencies,
are required. A local test used R 4.6.1 on Windows 11 x64 with Biobase 2.72.0,
caret 7.0-1 and pROC 1.19.1. This records a tested environment, not a guarantee
of identical results on another computer; no locked environment is provided.

Keep the wrapper, both scripts under `source/`, and the following seven files
under `data_root/` together:

```text
data_root/
  data/processed/GSE10334_01D_log2_gene_matrix.rds
  data/processed/GSE10334_01D_sample_map.csv
  data/processed/GSE30784_01D_log2_gene_matrix.rds
  data/processed/GSE30784_01D_sample_map.csv
  data/external_validation/original_GEO/GSE37991_ORIGINAL_GEO_ExpressionSet.rds
  data/external_validation/original_GEO/GSE37991_VERIFIED_sample_map.csv
  results/07_Major4_external_validation/02_mapping_overlap_QC/GSE37991_five_gene_probe_annotation.csv
```

The matrices labelled `01D` use GEO-processed data without an additional
between-array normalization. They are distinct from the normalized expression
matrices generated by the current Script 01 and must not be substituted for
them. The complete provenance of the 01D preparation and probe annotation is
not established by this package alone. The panel is CXCL1, CXCL6, CXCR4, RGS1
and CHST2.

## Check the inputs

In R or RStudio, set the working directory to `step07/` and run:

```r
local({
  old <- Sys.getenv("PD_OSCC_07_MODE", unset = NA_character_)
  on.exit(if (is.na(old)) Sys.unsetenv("PD_OSCC_07_MODE") else
    Sys.setenv(PD_OSCC_07_MODE = old), add = TRUE)
  Sys.setenv(PD_OSCC_07_MODE = "check_inputs")
  source("07_machine_learning_reproduction.R")
})
```

The check verifies files, package availability, fingerprints, sample order,
the fixed gene panel and the external cohort's pair structure. It fits no
models and writes no output files. A fingerprint mismatch stops the script;
investigate the inputs rather than bypassing the check. The two PD hashes
identify the currently supplied files: a hash manifest for the earlier 07A
inputs was not saved, so those hashes alone do not establish historical input
identity. The expected hashes also cover the two supplied source scripts.

## Run the analyses

From the same working directory, with write access, run:

```r
local({
  old <- Sys.getenv("PD_OSCC_07_MODE", unset = NA_character_)
  on.exit(if (is.na(old)) Sys.unsetenv("PD_OSCC_07_MODE") else
    Sys.setenv(PD_OSCC_07_MODE = old), add = TRUE)
  Sys.setenv(PD_OSCC_07_MODE = "run")
  source("07_machine_learning_reproduction.R")
})
```

The wrapper repeats the input checks, then writes a new timestamped folder
under `results/07_machine_learning/reproduction/` in the working directory.
It records input and source hashes, R session information, run status and a
comparison with the saved AUC summaries. See `07_run_status.txt` for
completion and `07_result_comparison.csv` for the five comparisons. Inspect
the console and partial outputs if the status is incomplete.

For a different layout, `PD_OSCC_07_SOURCE_DATA` can point to an existing
replacement root containing the **same** seven files at the relative paths
above; the hash checks still apply. `PD_OSCC_PROJECT_ROOT` can point to an
existing directory in which the `results/` tree should be created. For
nonstandard launch methods, `PD_OSCC_07_PACKAGE_DIR` can specify the existing
directory containing the wrapper and `source/`. Unset stale overrides when
returning to the default layout.

## What the analyses establish

For 07A, PD folds keep repeated biopsies from a patient together; OSCC folds
are stratified by outcome. Centering and scaling are estimated within each
training fold. The five-gene panel was selected using the full discovery data
before cross-validation, so the AUCs are conditional on this fixed panel and
may be optimistic; the procedure is not nested feature selection or an
independent validation of the selection process.

For 07D, the model is trained on GSE30784 and evaluated in GSE37991 (80
samples from 40 matched pairs). Its uncertainty is estimated by paired
patient bootstrap, and a paired label-swap test is also reported. Different
platforms can introduce expression-scale and calibration shifts. This test
does not establish clinical screening performance or biological progression.
GSE16134 overlaps the PD training dataset and is not independent external PD
validation. Earlier SVM analyses and the earlier training-sample permutation
test are not reproduced by this wrapper.

On the author's computer, a full run of this portable-path wrapper on
20 November 2026 reproduced the five saved AUC summary values within 1e-6:
mean-fold and pooled out-of-fold AUCs for PD and OSCC, and external OSCC AUC
(0.7900). This local comparison is not a test on another computer and does
not prove that every earlier analysis or historical input can be reconstructed.
