# Script 07 — черновик для проверки, не для публикации

Этот пакет предназначен для воспроизведения исправленных сохранённых анализов 07A и 07D: кросс-валидации фиксированной панели из пяти генов и внешней проверки OSCC. В копиях файлов `source/` личный путь заменён на переменную, которую передаёт главный скрипт; методы и случайные числа не изменены. Запускайте главный скрипт, а не файлы `source/` по отдельности. Изменённый вариант необходимо проверить в целевой среде.

Пять генов выбраны до кросс-валидации на всех обучающих данных, поэтому результаты CV условны и могут быть оптимистичны. GSE16134 не является независимой внешней проверкой PD из-за перекрытия образцов. Исходная SVM и ранее описанный тест перестановок на обучающей выборке в исправленную модель не входят. Данные 01D ранее обработаны в GEO, без дополнительной межмассивной нормализации; нормализованные матрицы текущего Script 01 — другие входные данные и не являются их заменой.

## Локальные входные данные

Для сохранения тех же входов нужен каталог `data_root` рядом с главным скриптом со следующей структурой:

```text
data_root/
  data/processed/GSE10334_01D_log2_gene_matrix.rds
  data/processed/GSE10334_01D_sample_map.csv
  data/processed/GSE30784_01D_log2_gene_matrix.rds
  data/processed/GSE30784_01D_sample_map.csv
  data/external_validation/original_GEO/GSE37991_ORIGINAL_GEO_ExpressionSet.rds
  data/external_validation/original_GEO/GSE37991_VERIFIED_sample_map.csv
  results/07_Major4_external_validation/02_mapping_overlap_QC/GSE37991_five_gene_probe_annotation.csv
```

Семь входных файлов включены только в этот локальный непубличный черновик; их контрольные суммы совпадают с ожидаемыми в главном скрипте. Перед включением в публичный репозиторий необходимо проверить возможность распространения всех данных и метаданных, а также документацию подготовки 01D и аннотации. Для PD сохранённый журнал предыдущего анализа не содержал контрольных сумм: текущий хеш не доказывает идентичность историческому входу.

По умолчанию используются файлы в `data_root`; другой существующий корень можно указать через переменную `PD_OSCC_07_SOURCE_DATA`. Если скрипт запускается не через `source()` и не через `Rscript`, путь к пакету можно задать через `PD_OSCC_07_PACKAGE_DIR`. Требуются пакеты Biobase, caret и pROC.

Режим по умолчанию `check_inputs` проверяет файлы и соответствие образцов, не обучая моделей и не записывая результатов. Режим `run` запускает анализ и создаёт новую папку `results/07_machine_learning/reproduction` относительно текущей рабочей директории или `PD_OSCC_PROJECT_ROOT`; старые результаты не перезаписываются. При расхождении контрольных сумм запуск останавливается.

20 ноября 2026 года копия с переносимыми путями прошла `check_inputs` и полный запуск `run` на этом компьютере: все пять сравнений AUC совпали с сохранёнными значениями в пределах 1e-6. Результаты теста записаны в отдельную папку, вне пакета и без перезаписи предыдущих результатов. Эта проверка не подтверждает запуск на другом компьютере. Копия ещё не готова для публикации: необходимо проверить условия распространения и документировать подготовку входов.
